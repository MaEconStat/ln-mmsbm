# NORTH 个人主页 / 研究栏目建议（27 英寸横屏 / 黑白）

研究页面使用三大分类：**理论｜方法｜应用**。它们是内容类型，而不是硕博论文目录；不按“论文、报告、会议、成果”划分。

首屏：小标题“研究”、一句简短定位、三个文本过滤器，随后以**横向长条研究条目**展示内容。不要把每篇研究笔记放在高度很大的静物图片下，也不要用只有白纸和笔记本的装饰性大图。

第一条内容：

- 标签：方法 / 统计建模 / 开源原型
- 标题：从二元网络到连续流量：多层随机块模型的拓展
- 摘要：以 TWIST 与混合多层随机块模型为起点，重建 Python 计算流程，并探索对数正态权重与生产者—消费者两侧社区的联合识别。
- 主动作：**阅读研究笔记**
- 次动作：**查看 Python 代码**（GitHub 仓库公开后）
- 学术归属：基于 Jing 等（2021），明确这是独立扩展而非原作者软件的官方实现。
- 状态：研究原型（非论文已发表成果）

详情页建议分为：问题 → 原论文模型 → 连续权重拓展 → 数学表示 → 算法实现 → 数值验证 → 适用边界与后续问题 → 引用与源码。

在 27 英寸大屏推荐 `max-width: 1320–1480px` 的文章容器、两栏组合（正文 65%、可折叠目录及源码 35%），正文 17–19px（注意严格按用户要求最小不少于 16pt）、明确图表标题、纯黑白层级。对于方法类笔记，使用真正的流程图和模拟图替代大面积空白装饰封面。

不要在主页宣传未经验证的“比原算法更准确”“实现稳定收敛”或“提出全新理论证明”。
